Bank Loan Report Analysis
1. Project Overview
The Bank Loan Report Analysis project presents a data-driven view of loan applications, funding, repayment performance, borrower characteristics, and credit risk. The interactive dashboard provides three main views: Summary, Overview, and Details.

The primary objective is to monitor lending performance, understand loan portfolio quality, identify application trends, and support data-informed lending decisions.

C. Loan Application Trends
The Overview dashboard displays monthly loan applications from January through December.

The chart indicates a general upward trend, with applications increasing from approximately 2.3K in January to 4.3K in December.

Key findings:

Application volume generally increases throughout the year.
December records the highest displayed monthly application count.
Growth in application volume may indicate increased lending demand or successful customer acquisition.

D. Geographic Analysis

This view can help identify:

E. Loan Term Analysis
The term distribution chart reports:


Loan Term	                    Applications	          Share
36 months	              Approximately 28K	            73.2%
60 months	              Approximately 10K	            26.8%

The 36-month term represents the majority of displayed applications.

A shorter loan term generally means a faster repayment schedule, while a longer term can spread payments over a greater period. A proper profitability comparison should also account for interest income, early repayment, delinquency, and default risk.
